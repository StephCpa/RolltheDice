依据：`analysis/2026-10-09-meta-method-review.md` §6 的批准范围。状态：**计划稿，未执行**。预算上限：**60 GPU 小时**（单张 A6000 计）。本计划是研究决策文档，不是已完成运行的报告。

## 0. 通过标准（进入阶段 1 的必要条件，全部满足才通过）

1. **复现方向一致**：Sibling＋Circle 两任务上，固定 seed NTP 与 teacherless 混合相对无 seed NTP 的方向性结论（多样性/有效性指标）与原论文 v4 图表方向一致；数值差异允许，须记录差值。
2. **评价核验**：两个任务的有效性判定、置换/命名等价归并逻辑通过独立复算（对已知实例手工/程序对拍）。
3. **吞吐实测点（C01 首证）**：200–500 步实测——无 seed NTP、固定配对、m=4 集合耦合三种训练的每步秒数与显存；集合耦合相对朴素 m² 实现的加速比（朴素实现只需在 200 步内测一次，不必跑完）。
4. **诊断可产出**：churn 曲线（π* 随步数的置换距离）与测试期 I(z;[y]) 代理（种子→输出等价类熵）在 m=4 原型上能稳定计算。

## 1. 工作包

- 克隆 `chenwu98/algorithmic-creativity`，固定快照 `7176dc7`；Python 环境按仓库 README。

### WP1：桥接基线（≤30 GPU 小时）
四条臂，两任务 ×（GPT-2, seq 128, bs 64, fp16；步数先 10k，吞吐外推到 40k 决定是否跑满）：
1. 无 seed NTP；
2. 固定 seed 配对 NTP（原论文设定）；
3. 原 teacherless 混合（按仓库 hybrid notebook 预处理）；
4. **固定种子集＋每轮随机双射（G1 中间对照）**——本计划新增，实现与臂 2 相同只是配对每轮随机重排。
- P-SFT 式重采样基线**推迟**到取得全文核实（G5）后再入阶段 1。
- 评价：沿用仓库 `eval_qa.py`；另按 §0.2 独立复算等价归并与有效性。

### WP2：m=4 集合耦合原型（≤18 GPU 小时）
- 数据侧：每个约束 c 采 m=4 个程序验证过的去重解（解不够 4 个的实例丢弃并计数）。
- 训练侧：teacherless 分支每轮对 4 个 seed 各一次前向 → 4×4 代价矩阵（logits 索引）→ Hungarian（`scipy.optimize.linear_sum_assignment`）→ 仅对被配对 4 对回传；NTP 混合项按原论文比例保留。
- 记录：每 100 步 dump π* 序列、匹配代价矩阵范数。

### WP3：诊断与首轮结论（≤6 GPU 小时，含重跑）
- churn：相邻窗口 π* 的 Cayley 距离均值；
- I(z;[y]) 代理：固定 32 个测试约束 × 每 seed 采 16 次 → 输出等价类条件熵；
- 覆盖：Circle 可枚举实例上的覆盖比例；U_N 同步报告。
- 产出 `runs/stage0-report.md`：四臂并排表 + C01 实测 + churn/I 曲线 + 与 §2 决策分支的对照结论。
