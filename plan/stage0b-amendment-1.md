## 2. 新臂规格锁定（批复条款）

- **tl_RN**：R 为一次性按预固定随机规则生成的组级固定双射（种子 777，与训练种子独立），
  全程不变、不看表现挑选。**采用非名义条件版**（R 与 N 组内无交叠，即每 seed 的 TL 目标 ≠ 名义目标）；
  需登记 R 与 N 的条目级重合率（应为 0）与结构级重合率（8859/10000 结构去重后同结构目标占比，如实报告）。
- **ntp_2tgt**：第二目标取 **N＋R**（非 N＋M：不依赖在线匹配，保持"简单基线"身份）；
  两目标各自正确 teacher-forcing 输入；损失权重 0.5/0.5，**总监督权重与单目标臂一致**
  （每 seed 每 visit 的 NTP 监督 token 预算不变，拆分给两目标）；无 TL 分支、无配对计算开销。
- 判读按批复分支表：MN 不过门槛→停；RN≈MN→保留固定随机对应、不称 Hungarian 必要；
  2tgt≥MN→保留简单监督方案；MN 稳定胜三者→继续研究匹配与分工机制；种子间分化→记录未决，不自动延长。
